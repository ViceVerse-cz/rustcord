# Native notification dependency licenses

Unmodified MIT license texts for notify-rust and its newly selected notification adapters/timer. Source versions are pinned by Cargo.lock; the crate archive checksums there identify each source archive. Libraries offer alternative licensing; these texts preserve the MIT option without changing upstream licensing. The objc2 upstream licensing notice is preserved as supplied, including its Apple SDK discussion; its registry archives and release tree do not provide complete license texts. Complete per-artifact transitive license assembly remains the documented release-hardening gate.
